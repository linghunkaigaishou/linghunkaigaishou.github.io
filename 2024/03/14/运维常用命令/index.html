windows常用命令

端口转发

1.设置端口转发规则：

增加一条端口转发规则：

netsh interface portproxy add v4tov4 listenaddress=本地IP listenport=本地侦听端口 connectaddress=远程IP connectport=远程端口

删掉一条端口转发规则：

netsh interface portproxy delete v4tov4 listenaddress=本地IP listenport=本地侦听端口

清空当前所有端口转发配置规则：

netsh interface portproxy reset

2.查询当前所有端口转发配置规则：

netsh interface portproxy show all

3.将配置信息备份(貌似只有配置导出没有配置导入功能)：

将配置信息输出到控制台的标准输出

netsh interface portproxy dump

将配置信息重定向到文件中

netsh interface portproxy dump > bakpeizhi.txt

FAQ:

  1. Windows 从 Windows 2000 开始就提供了最基本的端口转发功能，是基于 Windows 的 IP Helper 服务的，不仅可以提供端口转发功能，还可以通过将 IPv4 和 IPv6 的不同地址的数据进行转发，但是只可以转发 TCP 协议，暂不支持 UDP 协议。
  2. 若端口转发配置在系统重启以后重置，考虑在计划任务中添加开机配置端口转发任务。
  3. 防火墙规则检查
  4. 远程桌面超过最大连接终端数（任务管理器用户中断开和注销多余的用户）

Linux常用命令

创建sudo用户

1.创建新用户:

useradd 新用户

2.设置该用户密码：

passwd 新用户

3.将新用户添加到sudo组，以获得管理员特权：

usermod -aG wheel 新用户

FAQ：

默认情况下，在 CentOS 系统上，组成员wheel被授予 sudo 访问权限

磁盘操作

1.查看系统中的所有硬盘及其分区信息

fdisk -l

2.对新硬盘进行分区

fdisk /dev/sdb

3.格式化新分区为ext4文件系统

mkfs.ext4 /dev/sdb

4.创建挂载点

mkdir /data

5.挂载分区

mount /dev/sdb /data

显示所有已挂载的文件系统的信息，包括挂载点，验证挂载情况：

df -h

6.设置自动挂载（在/etc/fstab中添加以下行）

echo ‘/dev/sdb1 /mnt/mydisk ext4 defaults 0 0’ | tee -a /etc/fstab

验证自动挂载：

cat /etc/fstab

检查日志文件（如果自动挂载重启后没生效）：

journalctl -f | grep mount

journalctl -b | grep mount

尝试挂载 /etc/fstab 文件中列出的所有文件系统

mount -a

old version:

systemctl daemon-reload

sshd配置

vim /etc/ssh/sshd_config

修改端口，禁止root用户远程直接登录：

port 22

PermitRootLogin no

systemctl restart sshd

临时关闭SElinux

setenforce 0

永久关闭SElinux:

vim /etc/selinux/config

设置参数：

SELINUX=disabled

防火墙配置(基于firewall)

firewall-cmd –zone=public –add-port=80/tcp –permanent

firewall-cmd –zone=public –add-port=443/tcp –permanent

firewall-cmd –zone=public –add-rich-rule=’rule family=”ipv4” source address=”x.x.x.x/xx” port port=”xx” protocol=”tcp” accept’ –permanent

firewall-cmd –reload

firewall-cmd –zone=public –list-all

端口转发(基于firewall)

1.查看firewalld运行状态：

systemctl status firewalld

2.添加一条端口转发规则：

firewall-cmd –add-forward-port=port=本地侦听端口:proto=tcp:toport=远程端口:toaddr=远程IP –permanent

移除一条端口转发规则：

firewall-cmd –remove-forward-port=port=本地侦听端口:proto=tcp:toport=远程端口:toaddr=远程IP –permanent

3.允许信任IP访问侦听端口：

firewall-cmd –permanent –zone=public –add-rich-rule=”rule family=”ipv4” source address=”信任IP地址段” port protocol=”tcp” port=”侦听端口” accept”

或者

firewall-cmd –zone=public –add-port=侦听端口/tcp –permanent

4.开/关地址伪装功能（NAT）：

开启地址转发功能：

firewall-cmd –add-masquerade –permanent

查看包转发功能是否开启（默认为0-未开启，1-包转发开启）：

sysctl net.ipv4.ip_forward

关闭地址转发功能：

firewall-cmd –del-masquerade –permanent

或者

firewall-cmd –remove-masquerade –permanent

5.重新加载配置文件：

firewall-cmd –reload

6.查看防火墙规则列表：

firewall-cmd –list-all

FAQ:

默认没有开启包转发功能。即系统只处理目的地为本机的数据包，不会转发发往其它地址的数据包。在内核中有相应配置选项net.ipv4.ip_forward 默认设置为0。可以通过命令sysctl net.ipv4.ip_forward=1手动开启包转发功能。防火墙的masquerade功能进行地址伪装(NAT)，私网访问公网或公网访问私网都需要开启此功能来进行地址转换，否则无法正常互访。通过命令firewall-cmd –add-masquerade开启此功能，开启之后net.ipv4.ip forward的值自动被设置为1，即centos启用包转发。当然，如果启用了masquerade而不启用包转发的设置是没有意义的，相当于只有本机的数据能进出网络接口，那么NAT就没有意义了。

Centos7更换yum源

配置阿里镜像源：

  • 备份原有仓库文件：mkdir /etc/yum.repos.d/backup && mv /etc/yum.repos.d/*.repo /etc/yum.repos.d/backup

  • 下载阿里云仓库文件：
wget -O /etc/yum.repos.d/CentOS-Base.repo http://mirrors.aliyun.com/repo/Centos-7.repo  
wget -O /etc/yum.repos.d/epel.repo http://mirrors.aliyun.com/repo/epel-7.repo

  • 清理并更新缓存：yum clean all && yum makecache

数据库常用命令

更新某条数据

update 表名 set 需要更新的列名 = ‘更新的列值’ where 过滤字段 = ‘过滤字段值’

举例：

update 表名 set ICKKH=’22719673797880’ where RYBH = ‘20220718’

统计数据条数

SELECT COUNT(*) FROM 数据表名;

查询数据库下的表名

select name from sys.tables;

查询数据表下面的字段列表

select table_name,column_name,data_type,CHARACTER_MAXIMUM_LENGTH from information_schema.columns where table_name = ‘表名’

查询数据库下的视图名

SELECT table_name FROM information_schema.views;

查询视图下的字段列表

SELECT
COLUMN_NAME as ‘FieldName’,
DATA_TYPE as ‘DataType’,
CHARACTER_MAXIMUM_LENGTH as ‘MaxLength’
FROM
INFORMATION_SCHEMA.COLUMNS
WHERE
TABLE_NAME = ‘视图名’
